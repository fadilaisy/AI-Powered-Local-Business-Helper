# Design taste

- Favors light/warm palettes (parchment/ivory, coral, lime) with hard 2px borders, offset shadows, and tactile press/lift states — neobrutalist-editorial over dark glass / fintech gradients. Confidence: 0.75
- Wants motion and interaction to be real rather than described: shader/WebGL backgrounds, pointer-reactive elements, animated state transitions. Confidence: 0.7
- Treats contrast, correct semantic roles, and `prefers-reduced-motion` support as non-negotiable; darkens accents until AA passes instead of accepting a flagged ratio. Confidence: 0.7
- Prefers distinctive, ownable typefaces over common UI defaults; dislikes over-crushed negative display tracking. Confidence: 0.6
- Prefers a tangible physical metaphor for abstract product features (a hash rendered as a torn receipt/stamp) over explaining the feature in copy. Confidence: 0.6
- Mobile should collapse to one primary action with a reachable sticky CTA rather than mirroring the desktop layout. Confidence: 0.55
- Avoids perpetual attention-grabbing motion loops; static or one-shot cues read as more premium. Confidence: 0.55
- When given a website reference, prefers an app-wide visual redesign guided by it while preserving the project's existing features, workflows, and page structure. Confidence: 0.9
