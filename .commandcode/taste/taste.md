# Taste

## Communication
- Gives ultra-terse, lowercase instructions and expects the work carried end-to-end without clarifying questions or check-ins. Confidence: 0.85
- Acceptance is implied by silence — deliver the complete, runnable artifact rather than a partial plan or a request for approval mid-way. Confidence: 0.6

## Workflow
- Wants design/UI exploration delivered as a single self-contained, no-build HTML file in a scratch folder (e.g. `.impeccable/index.html`) so every concept can be opened and clicked through in a browser. Confidence: 0.9
- Keeps exploration/scratch output out of the production source tree; concepts get promoted into real app code only after one is chosen. Confidence: 0.7
- Prefers a bounded set of clearly distinct, numbered directions over one merged recommendation. Confidence: 0.65
